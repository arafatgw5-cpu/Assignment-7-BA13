#  Keen Keeper

##  Description
Keen Keeper is a modern friend tracking web application that helps you stay connected with your important people. You can track interactions, manage contacts, and visualize communication stats easily.

---

##  Technologies Used
- Next.js
- React
- Tailwind CSS
- DaisyUI
- LocalStorage
- Recharts

---

##  Key Features

### 1.  Interaction Tracking
Track calls, texts, and video interactions with your friends using local storage.

### 2.  Timeline & Filtering
View all interactions in a timeline and filter them by type (Call, Text, Video).

### 3.  Statistics Dashboard
Visualize your communication data with beautiful charts using Recharts.
